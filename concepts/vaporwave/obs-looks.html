Cinema looks for OBS

The lobby and auditorium each change filters every 30 seconds by default. Choose the room in the control panel to select a filter, show the original picture, or adjust automatic changes from 5 to 600 seconds. A manual selection holds until you turn automatic changes back on. Normal and Moody share the lobby setting.

Packaged OBS scenes

To use the filter controls inside a scene, open the browser source’s Interact window in OBS and press Shift+F. For a dedicated operator view, add filtercontrols=1 to the scene URL.

Install obs-shaderfilter, restart OBS and run START.bat. The included browser sources carry their shader text and the local OBS bridge applies your room selections. The table below shows eight tested combinations. The lobby collection starts on Neon rain at 85% and the auditorium on Pearl diffusion at 55% until the bridge applies the controls.

Hosted scenes or your existing collection

On the hosted setup page, Use this room’s cinema filter settings applies your current room choices when creating the scenes. Clear it to start both rooms on the original picture. On OBS 33 or newer, keep the linked control panel open on the OBS computer while using the filters, including when only the lobby is visible. To use the shader by hand on a separate browser source, follow these steps.

  1. Install obs-shaderfilter and restart OBS. Download the cinema shader to a folder you will keep. If you unzipped DinkDonk Cinema, the same file is in the obs folder.
  2. In OBS, right-click the browser source that opens lobby.html or auditorium.html and choose Filters. Hosted setup names them DinkDonk Lobby (browser) and DinkDonk Auditorium (browser). In the packaged collection, open Lobby (src) or DinkDonk Cinema to find the source.
  3. Under Effect Filters, add User-defined shader. Enable Load shader text from file and select cinema-looks.shader. Choose a Cinema look and set Strength (%) from the table.
  4. On the auditorium browser source, place the look below its enabled color key and check Keep film cutout aligned (keyed browser source). This preserves the film opening and keeps the film source’s own colors. On the lobby browser source, leave the cutout option off.
