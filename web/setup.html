1 · Connect to OBS

This page sets everything up in your OBS for you. For that it talks to OBS's built-in remote control (the "WebSocket server"), which is off until you switch it on. Do this on the PC that runs OBS, with OBS open.

  1. In OBS's menu bar, click Tools, then WebSocket Server Settings.
    1 2
    No "WebSocket Server Settings" there? Your OBS is older than version 28: update it from obsproject.com.
  2. In the window that opens:
    1 2 3 4
    1. Tick Enable WebSocket server. Leave Server Port at 4455 and Enable Authentication ticked.
    2. If the Server Password box is empty, click Generate Password.
    3. Click Show Connect Info, then the Copy button next to Server Password. Close that small window.
    4. Click Apply, then OK.
  3. Paste the password into the box below and click Connect. Your browser may ask whether this site can look for and connect to devices on your local network: click Allow. That only lets this page reach OBS on your own PC.
  4. Optional, for the film moving on the cinema screen: install the obs-shaderfilter plugin (download the Windows installer from the newest release, close OBS, run it, open OBS again). Without it everything still works; the cinema screen just stays green, so you can key your film onto it yourself.
It says OBS is not reachable, or the password is wrong
  • Not reachable: is OBS open on this PC? Is Enable WebSocket server ticked, and did you click OK? Is the port 4455 (or the same number as in OBS)?
  • Blocked the local network question by mistake? Click the icon to the left of the address bar, open Site settings, set Local network access to Allow, and reload this page.
  • Password is wrong: copy it again from Show Connect Info. If you clicked Generate Password, click Apply/OK in OBS before connecting.
  • Use Chrome or Edge on the OBS PC. Phones and other computers can't set up OBS (but the control panel works on a phone).

2 · Create the scenes

This adds three scenes to your current scene collection: DinkDonk Lobby, DinkDonk Cinema (the auditorium) and Film screen (src), a helper that holds your film source. Running it again updates them; nothing else is changed.

Check it · live from OBS

The "DinkDonk Cinema" scene as OBS renders it. Open the control panel, pick Auditorium and click Lights down, then Film: the film should sit exactly on the cinema screen.

3 · Every stream

Switch to the DinkDonk scenes when you're on break or before the film. The control panel moves the camera, runs the auditorium phases (seating › lights down › film › lights up) and the automatic director. It works from your phone too.

Film on the cinema screen: on OBS 32 and older the auditorium talks to OBS by itself. Newer OBS (33+) won't let a website inside OBS reach it, so then keep the control panel open in this browser on this PC during the film: it passes the screen position on to OBS. Its top line says whether that link is up.
